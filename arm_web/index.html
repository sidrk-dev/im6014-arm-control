Connect and move J1 One motor · ID 0
1. Connect the motor USB-RS485 · Channel D
Connect the USB-RS485 adapter, then select Refresh.
Using a different adapter?

Enter its port path only if you know which adapter is connected to the motor.

Motor ID 0 · 6 Mbaud. Connection is confirmed only by fresh J1 feedback.

2. Check the motor Fresh Stop feedback required

After connecting, select Check motor. This reads status and keeps movement locked until the motor confirms Stop.

Startup timeout: the motor will stay stopped. Confirm it is secure before acknowledging this timeout.

3. Set J1 zero No movement
Point J1 where you want 0° to be, then choose Set J1 zero here. This changes the software reference only; it does not move the motor. Default travel is −90° to +90°.

Choose while stopped. Release the keys and center the sticks before enabling movement.
In direct control, release the keys or center the stick to hold J1. Automatic path follow keeps moving until you press STOP, Esc, or controller B.
