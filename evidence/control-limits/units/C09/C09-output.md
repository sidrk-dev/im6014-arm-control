#### Key Design Decisions
1. **Quantization B Inward Projection**: Pure monotonic binary search over raw motor position integers [−2147483648, 2147483647] maps requested targets to inward safe representable endpoints. Rounding overshoot past `q_min_rad` or `q_max_rad` is prevented without floating tolerances.
2. **Canonical Packet Binding**: Canonical command packets are prepared and bound directly in [`RefreshPlan`](file:///tmp/pstack-c07-c16-20261008-smgcfm_v/C09-workbench/joint_contract.py#L225-L255), eliminating encode-decode-reencode roundtrip drift.
3. **Atomic Goal Admission & Dispatched Records**: Target submission validates all joints atomically. Proposed/dispatched records report the actual inward decoded reference rather than falsely recording out-of-grid requests.
4. **Pre-Write Measured Gate**: [`claim_dispatch`](file:///tmp/pstack-c07-c16-20261008-smgcfm_v/C09-workbench/joint_controller.py#L650-L685) verifies measured joint positions against bounds immediately prior to granting write authority.
