# Control-limit verification evidence

The active implementation is in the repository root. Unit source snapshots preserve every rejected and accepted author artifact; they are historical evidence, not active modules. Receipts distinguish requested routes and backend reports from independently established identity. Every failed review seat remains a dropout.

Large generated proof JSON files are stored losslessly as `.json.gz`. `compressed-proof-index.json` names each original path, archive path, byte count and SHA256 of exact decompressed original bytes. Recover with gzip decompression; no source sample, receipt, failure or certificate was discarded. Raw logs, source snapshots, receipts and acceptance metadata remain individually readable. Large inline review prompts/diffs are also retained as gzip files. The required protocol CRC fixture remains uncompressed at `evidence/boundary/vendor-crc-vectors.json`.

Parent verification results contain paths from the retained run and reflect the checked source copies at that time. Artifact directories preserve raw checks and captures; acceptance entries and milestone ledger name actual results. Software/fake-I/O/disconnected GUI evidence does not establish physical motor protection.
